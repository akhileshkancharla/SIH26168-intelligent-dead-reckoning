implementation and its helpers live under `core/navigation/verification/` and
are offline verification code only. Production C++ does not import, invoke, or
bind Python. The C++ namespace and include spelling remain `s2_oracle` so the
accepted implementation bytes do not need mechanical edits.

Eigen discovery, version pinning, CMake target integration, and test target
wiring are intentionally deferred to issue #38. Public API design and JNI are
also excluded. Until #38 is complete, the imported C++ files are present but
are not added to the repository build graph.

# WP-08.1 S6B1 road-graph import lineage

## Decision boundary

placing private artifact bytes in the repository. Architecture Revision 3 is
authoritative: S6B1 is a conditional foundation for C-10/C-18 and I-21, not
evidence that runtime graph access, top-K matching, Android rendering, a safe
field route or navigation accuracy is complete.

## Verification and downstream boundary

`tools/maps/verify_s6b1_artifact.py` verifies the external delivery without
extracting it. Hash, member-set, attribution, bounds, test, determinism or route
status mismatch fails closed and rejects the map package.

WP-08.1 does not implement WP-08.2 SQLite access or any later spatial lookup,
top-K candidate, ambiguity, abstention or adversarial matcher work. C-07 remains
the sole navigation-state owner; any future map output is a bounded proposal and
cannot overwrite the scientific navigation state.

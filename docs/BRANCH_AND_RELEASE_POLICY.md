# Branch and Release Policy

`main` is pull-request-only after bootstrap protection is activated. Review approval is author-aware: Akhilesh-authored pull requests require Faisal's current-head approval, Faisal-authored pull requests require Akhilesh's current-head approval, and all other pull requests require current-head approvals from both Akhilesh and Faisal. Current CODEOWNER approval, last-push approval, resolved conversations, required checks, and linear history remain mandatory. Self-approval never counts. Squash merge is the only allowed merge mode. `submission-v1.0-rc1` may be created only after internal verification and does not certify unresolved scientific gates.

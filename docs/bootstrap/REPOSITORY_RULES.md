# Repository Rules

`main` requires pull requests and author-aware approval: Akhilesh requires Faisal's current-head approval, Faisal requires Akhilesh's current-head approval, and every other author requires current-head approvals from both. Current CODEOWNER approval, last-push approval, resolved conversations, required checks, and linear history remain mandatory; self-approval never counts. Force pushes, deletions, direct pushes, merge commits, rebase merges, and administrator bypass are disabled where the plan/API supports them. Unauthorized issue closure is reversed and audited; GitHub does not prevent the close button itself.

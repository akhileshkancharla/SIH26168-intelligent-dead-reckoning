# Contributing

Work from `issue/WP-XX.Y-short-description` branches. Each child issue normally maps to one branch, one bounded task, one pull request, and one evidence set.

Use `Relates to #123`; automatic close keywords are prohibited. Approval requirements are author-aware: pull requests authored by `akhileshkancharla` require current-head approval from `FaisalTabrez`; pull requests authored by `FaisalTabrez` require current-head approval from `akhileshkancharla`; every other author's pull request requires current-head approval from both. Every pull request also requires current CODEOWNER approval, resolved conversations, last-push approval, and passing checks. Self-approval never counts.

Daily updates use:

```markdown
## Daily update

- Completed:
- Evidence/commit:
- Current blocker:
- Next action:
- Expected completion:
```

Evidence—not checkbox state—determines completion. Never commit private data, credentials, generated scientific claims, or fabricated results.
